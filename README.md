# «Ломаем рынок найма»

Локальный лендинг по странице `concept` [этого макета Figma](https://www.figma.com/design/esHeuYwAGf6wLnabEdMiBb/%D0%A1%D0%B0%D0%B9%D1%82-%D0%98%D1%80%D0%B0-%D0%9C%D0%BE%D1%82%D0%BE%D1%80%D0%B8%D0%BD%D0%B0---%D0%9A%D0%B0%D0%B4%D0%BE%D0%BC%D0%B5%D1%86?node-id=1-3). Стек: HTML, CSS, JavaScript, PHP для приёма откликов и Google Apps Script для записи в таблицу. Установка пакетов не нужна.

## Посмотреть локально

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173/`. Без настроенного Apps Script тестовые отклики сохраняются в `.local-submissions/` и не отправляются в Google. Эта папка исключена из Git. Для проверки реальной интеграции локально задайте `APPS_SCRIPT_URL` и `APPS_SCRIPT_SECRET` в окружении перед запуском сервера.

## Подключить Google Таблицу

1. В Google Таблице с ID `1WjuYVQz-R3EakW4IVwxY1Nj_J5vTohr80Q8u6MF0s10` откройте **Расширения → Apps Script** и вставьте код из `integrations/google-apps-script/Code.gs`.
2. В **Настройки проекта → Свойства скрипта** задайте `SUBMISSION_SECRET` — длинную случайную строку. По желанию задайте `DRIVE_FOLDER_ID`, чтобы прикреплённые резюме сохранялись в выбранную папку Google Диска. Без этого свойства файлы сохранятся в корне Диска владельца скрипта.
3. Опубликуйте скрипт как **Веб-приложение**: запуск от имени владельца, доступ — «Все». На запрос Google разрешите доступ к Таблице и Диску. Скопируйте URL развертывания, который заканчивается на `/exec`.
4. На хостинге создайте `api/config.php` по образцу `server/config.example.php`. Вставьте URL и тот же секрет. Не добавляйте этот файл в Git. Сервер отправит данные в Apps Script, который добавит строку на лист «Отклики» и сохранит файл резюме на Google Диске.

Форма возвращает успех только после ответа Apps Script об успешной записи. Если интеграция не настроена или запись не удалась, посетитель увидит ошибку и сможет повторить отправку.

## Подготовить для REG.RU

```sh
npm run build
```

Сборка создаст `regru-dist/`: статические файлы, PHP-обработчик и пример конфигурации. Загрузите **содержимое** этой папки в корневой каталог нового сайта в панели REG.RU, как в проекте портфолио. После загрузки создайте `api/config.php` на хостинге и проверьте тестовый отклик. В хостинге нужны PHP с расширениями `curl` и `fileinfo`, HTTPS, `upload_max_filesize` не меньше 10 МБ и `post_max_size` не меньше 12 МБ. MySQL для этого лендинга не требуется.

Исходники хранятся в [ffe-event-motorina-kadomits](https://github.com/Ilya1999-sys/ffe-event-motorina-kadomits). FTP-деплой для REG.RU можно настроить по образцу портфолио после добавления сайта в панели хостинга. `regru-dist/`, личные отклики и секреты исключены из Git.

## Что где лежит

- `site/` — готовая страница и оптимизированные изображения;
- `source-assets/` — оригиналы PNG, выгруженные из Figma;
- `server/` — PHP-обработчик для хостинга;
- `integrations/google-apps-script/` — скрипт записи в Таблицу и загрузки резюме на Диск;
- `scripts/package-regru.mjs` — сборка папки для загрузки.

В макете тексты заданий были перепутаны местами: описание интерфейса стояло под «редакторами», а работа с текстами — под «дизайнерами». На сайте они размещены по соответствующим профессиям. Даты `9–19 ноября` и дедлайн `16 ноября` взяты из макета.

Заголовки используют локально установленный Audex. Перед публикацией проверьте право на использование файла шрифта на сайте и в репозитории.
